# Резервное копирование базы данных Mebelgrad KIS

Система автоматического резервного копирования базы данных для ERP-системы "МебельГрад".

## Настройка

### 1. Настройка через веб-интерфейс

1. Войдите в систему как администратор
2. Перейдите в раздел MDM (Управление данными)
3. Нажмите "Резервное копирование"
4. Настройте параметры:
   - **Включить автоматическое резервное копирование**: Включите для активации
   - **Частота**: Ежедневно / Еженедельно / Ежемесячно
   - **Время**: Время создания копии (HH:MM)
   - **Срок хранения**: Количество дней хранения копий
   - **Путь**: Директория для хранения резервных копий

### 2. Настройка планировщика задач

#### Windows (Планировщик задач)

1. Откройте **Планировщик задач** (Task Scheduler)
2. Создайте новую задачу:
   - **Имя**: Mebelgrad KIS Backup
   - **Триггер**: Ежечасно или по расписанию
   - **Действие**: Запуск программы
     - **Программа**: `python.exe`
     - **Аргументы**: `scripts\run_scheduled_backup.py`
     - **Рабочая папка**: Путь к проекту

#### Linux (Cron)

Добавьте в crontab (`crontab -e`):

```bash
# Ежечасно проверка необходимости резервного копирования
0 * * * * cd /path/to/mebelgrad_kis && python scripts/run_scheduled_backup.py
```

## Ручное управление

### Создание резервной копии

```bash
python scripts/backup_database.py --create
```

### Проверка необходимости копирования

```bash
python scripts/backup_database.py --check
```

### Обновление расписания

```bash
python scripts/backup_database.py --schedule
```

## Структура резервных копий

Резервные копии сохраняются в формате:
```
mebelgrad_kis_backup_YYYYMMDD_HHMMSS.db
```

Пример: `mebelgrad_kis_backup_20231201_020000.db`

## Восстановление из резервной копии

1. Остановите приложение
2. Замените файл базы данных резервной копией
3. Запустите приложение

## Безопасность

- Резервные копии содержат все данные системы
- Храните копии в безопасном месте
- Регулярно проверяйте возможность восстановления
- Для долгосрочного хранения используйте внешние носители

## Мониторинг

Логи операций:
- `backup.log` - логи создания резервных копий
- `scheduler.log` - логи работы планировщика

## Устранение неполадок

### Копии не создаются

1. Проверьте права доступа к директории
2. Проверьте настройки в веб-интерфейсе
3. Проверьте логи на ошибки

### Планировщик не работает

1. Проверьте путь к Python
2. Проверьте рабочую директорию
3. Проверьте логи планировщика
